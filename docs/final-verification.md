# Финальная проверка проекта

Дата проверки: 24.05.2026.

Ветка проверки: `release/coursework-v1`.

Базовая ветка: `docs/coursework-package`.

## Цель этапа

На шестом этапе выполнена итоговая проверка проекта перед защитой курсовой работы. Проверка подтверждает, что проект можно развернуть с нуля, заполнить тестовыми данными, запустить backend и frontend, открыть интерфейс в браузере и получить отчеты по данным системы.

## Проверенный состав проекта

- Laravel backend с миграциями, моделями, seed-данными, API и автотестами.
- Клиентский frontend на HTML, CSS и JavaScript.
- Документация: требования, модель данных, API, пояснительная записка, руководство пользователя, инструкция по развертыванию, чек-лист тестирования и структура презентации.

## Команды проверки

```powershell
cd backend
composer install
Copy-Item .env.example .env -Force
php artisan key:generate
New-Item .\database\database.sqlite -ItemType File -Force | Out-Null
php artisan migrate:fresh --seed
php artisan test
```

```powershell
cd frontend
python -m http.server 5173 --bind 127.0.0.1
```

```powershell
cd backend
php artisan serve --host=127.0.0.1 --port=8000
```

```powershell
node --check frontend/app.js
```

## Проверенные API-сценарии

- `GET /api/events` возвращает список мероприятий.
- `GET /api/reports/bookings` возвращает сводку по бронированиям.
- В seed-данных доступны 2 мероприятия, 4 бронирования и отчетные показатели.
- В отчетах отображаются 8 забронированных билетов, сумма 19 000 рублей и выручка 2 200 рублей.

## Итог

Проект готов как рабочая версия для демонстрации на оценку «хорошо»: реализована предметная область, есть backend API, клиентский интерфейс, отчеты, тестовые данные, автотесты и комплект базовой документации. Дальнейшая доработка для более высокой оценки может включать полноценную авторизацию в интерфейсе, расширенный дизайн ролей и экспорт отчетов в файлы.
