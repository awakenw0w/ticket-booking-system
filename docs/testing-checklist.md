# Чек-лист тестирования

Документ фиксирует проверки для демонстрации и пояснительной записки.

## Автоматические проверки

Команда:

```powershell
cd backend
php artisan test
```

Ожидаемый результат:

- все тесты проходят успешно;
- проверяется структура БД;
- проверяется seed;
- проверяется CRUD API;
- проверяется бронирование;
- проверяются отчеты.

## Проверка запуска

| N | Действие | Ожидаемый результат | Статус |
| --- | --- | --- | --- |
| 1 | Выполнить `composer install` | Зависимости установлены | Выполнено |
| 2 | Создать `.env` | Файл окружения создан | Выполнено |
| 3 | Выполнить `php artisan key:generate` | Ключ приложения создан | Выполнено |
| 4 | Выполнить `php artisan migrate:fresh --seed` | БД создана и заполнена | Выполнено |
| 5 | Запустить `php artisan serve` | Backend доступен на `127.0.0.1:8000` | Выполнено |
| 6 | Запустить frontend через `python -m http.server` | Frontend доступен на `127.0.0.1:5173` | Выполнено |

## Проверка отчетов

| N | Действие | Ожидаемый результат | Статус |
| --- | --- | --- | --- |

## Остаточные риски

- Нет полноценной авторизации.
- Нет экспорта отчетов в файл.
- Нет интеграции с платежной системой.
- Нет промышленного логирования и мониторинга.

Для оценки "хорошо" эти ограничения допустимы, так как MVP, API, CRUD, отчеты, тесты и документация реализованы.
